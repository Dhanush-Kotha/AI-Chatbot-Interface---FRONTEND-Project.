# ✨ IntelliChat – AI Chatbot Interface

IntelliChat is a modern, responsive chatbot interface developed using **HTML, CSS, JavaScript, and React**. It provides an interactive chat experience with a clean UI and locally stored conversation history.

## 🚀 Features
- Modern dark-themed chatbot interface.
- Interactive message prompt box.
- Recent chat history in the sidebar.
- LocalStorage for conversation persistence.
- New Chat functionality.
- Responsive user interface.
- Demo-mode responses.

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript
- React.js
- Vite
- Browser LocalStorage

## ⚙️ Installation

```bash
git clone YOUR_REPOSITORY_URL
cd IntelliChat
npm install
npm run dev
```

Open the localhost URL displayed in your terminal.

## 📂 Key Components
- `Sidebar.jsx` – Chat history and navigation.
- `ChatWindow.jsx` – Displays conversations.
- `Message.jsx` – Displays individual messages.
- `PromptBox.jsx` – Handles user input.
- `App.jsx` – Main application component.
